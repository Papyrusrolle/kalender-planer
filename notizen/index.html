Notizen

…
Wähle links eine Notiz oder lege mit „+ Neu“ eine an.
Diese Notiz enthält Inhalte (z. B. Bilder, Tabellen oder eingerückte Blöcke), die die App nicht bearbeiten kann. Titel und Tags lassen sich ändern – den Text bitte in Notion bearbeiten.

Anmelden

Die Notizen sind mit demselben Passwort geschützt wie dein Kalender. Es bleibt auf diesem Gerät gespeichert.

Mit Notion verbinden

  1. Auf notion.so/profile/integrations eine interne Integration anlegen (Name z. B. „Notiz-App“) und den Schlüssel kopieren.
  2. In Notion eine Datenbank anlegen (z. B. ganzseitige Tabelle „Notizen“).
  3. In der Datenbank oben rechts ••• → Verbindungen → deine Integration hinzufügen.
  4. Den Link der Datenbank kopieren (••• → Link kopieren) und hier einfügen.

Der Schlüssel wird nur auf deinem Server gespeichert, nicht auf den Geräten. Die Spalten „Tags“ und „Angepinnt“ werden bei Bedarf automatisch angelegt.

Als App installieren
iPhone: in Safari Teilen → Zum Home-Bildschirm.
Windows: in Edge … → Apps → Diese Seite als App installieren (Chrome: Installieren-Symbol in der Adressleiste).
